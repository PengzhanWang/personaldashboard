# 项目全屏工作台 · 设计共识

## 已确认决策
| # | 议题 | 结论 |
|---|---|---|
| 1 | 架构 | 先在现有网页版上开发；数据结构按本地优先设计，以后转本地运行时可直接复用 |
| 2 | 看板列 | 按状态分列；类型用图标/色点和标签区分，可以按类型筛选 |
| 3 | 本地文件 | 网页版只存路径文本。拖入文件时自动填文件名和类型，配合按项目记住的「本地文件夹前缀」拼出完整路径；条目上有「复制路径」按钮 |
| 4 | 在线资源 | 一次粘贴多个链接（每行一个或整段文字）→ Worker `/api/unfurl` 抓取标题并识别类型 → 预览编辑后批量加入看板 |
| 5 | 适用范围 | 所有卡片都能展开。卡片有条目时，画布上显示「封面」（进度条、各类型数量、第一列的下一条）；原文字内容放到笔记栏 |
| 6 | 列配置 | 列模板：通用（待办/进行中/完成）、学习（待学/学习中/已掌握）、素材收集（收集/筛选/采用）、空白；列可改名、增删、排序；**最后一列 = 完成**，用来算进度 |
| 7 | 条目字段 | 标题、类型（任务/链接/视频/音频/文档/本地文件/图片）、链接或路径、标签、备注、可选截止日期、详细笔记（Markdown） |
| 8 | 电脑端布局 | 顶部（项目名、进度、类型筛选、添加）+ 中间看板 + 右侧可收起栏（项目笔记 ⇄ 条目详情），按 Esc 逐级返回 |
| 9 | 手机端 | 按列分组的竖向清单 + 勾选框（勾上移入完成，取消勾选回到原来的列）；已完成组默认折叠；可以粘贴链接添加；不支持拖动 |
| 10 | 隐私 | 沿用卡片隐藏遮罩（打开工作台前先显示遮罩）；新功能不考虑公司模式 |
| 11 | 导出 | 暂不做；保证数据结构干净即可 |

## 数据结构
- **表 `Items`**：`id, created_at, updated_at, updated_by, version, deleted, card_id, column_id, prev_column_id, sort, type, title, url, tags, note, due, body_md`
  - `prev_column_id` 用于手机端取消勾选时回到原来的列。
- **列配置**：存在卡片的 `layout_json.columns`，格式为 `[{ id, name }]`，最后一列就是完成列（列数 ≥ 2 时生效）。不改 `Cards` 表结构。
- 旧卡片的 `content_md` 原样保留，作为项目笔记显示。

## 分阶段交付进度
- [x] **第 1 阶段**：数据层（`Items` 表）+ 全屏工作台（看板拖拽、条目增删改、列模板、项目笔记与条目详情侧栏）
- [x] **第 2 阶段**：批量粘贴链接 + Worker `/api/unfurl` 标题抓取 + 拖入本地文件（含目录前缀记忆）
- [ ] **第 3 阶段**：画布卡片封面 + 手机端勾选清单
